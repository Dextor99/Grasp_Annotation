# Debug cube asset

This is an independent, watertight 60 × 40 × 40 mm cube used only for Gate 2–4
validation.  The OBJ coordinates are metres, matching the dedicated baseline
environment.  `debug_cube.sdf` was generated from this OBJ with the vendored
SDFGen tool at a 64³ grid (1.11111 mm spacing, five-cell padding).

The original project meshes are not copied or modified by these checks.
